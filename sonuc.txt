           BÖLÜM 4: POSTMAN İLE TEST REHBERİ (ADIM ADIM)
════════════════════════════════════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────────────────────────────────
 ADIM 1: POSTMAN'DA ORTAM DEĞİŞKENLERİ OLUŞTUR
──────────────────────────────────────────────────────────────────────────────────────

  1. Postman'ı açın → sağ üst "Environments" → "+" ile yeni ortam oluşturun
  2. Adını "SpringBank" koyun ve şu değişkenleri ekleyin:

  ┌────────────────────┬───────────────────────────────────┐
  │  Değişken Adı       │  Başlangıç Değeri                 │
  ├────────────────────┼───────────────────────────────────┤
  │  base_url           │  http://localhost:8095             │
  │  access_token       │  (boş bırakın)                    │
  │  refresh_token      │  (boş bırakın)                    │
  └────────────────────┴───────────────────────────────────┘

  3. Save ile kaydedin ve bu ortamı seçili yapın.


──────────────────────────────────────────────────────────────────────────────────────
 ADIM 2: TOKEN ALMA VE OTOMATİK KAYDETME
──────────────────────────────────────────────────────────────────────────────────────

  1. Yeni request: POST → {{base_url}}/api/auth/login
  2. Body → raw → JSON:
     {
         "email": "testuser@bank.com",
         "password": "pass123"
     }

  3. Scripts sekmesi → "Post-response" kısmına şu kodu yapıştırın:
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  if (pm.response.code === 200) {                                            │
  │      var jsonData = pm.response.json();                                     │
  │      pm.environment.set("access_token", jsonData.access_token);             │
  │      pm.environment.set("refresh_token", jsonData.refresh_token);           │
  │      console.log("✅ Token başarıyla kaydedildi!");                          │
  │  }                                                                          │
  └─────────────────────────────────────────────────────────────────────────────┘

  4. "Send" → Token otomatik kaydedilir!


──────────────────────────────────────────────────────────────────────────────────────
 ADIM 3: TOKEN İLE İSTEK GÖNDERME (3 YÖNTEM)
──────────────────────────────────────────────────────────────────────────────────────

  ═══ YÖNTEM 1: Authorization Tab (En Kolay) ═══
  1. Yeni request → "Authorization" sekmesi
  2. "Auth Type" → "Bearer Token"
  3. Token alanına: {{access_token}}
  4. Send!

  ═══ YÖNTEM 2: Manuel Header ═══
  Headers sekmesinde:
     Key:   Authorization
     Value: Bearer {{access_token}}

  ═══ YÖNTEM 3: Collection Level (EN İYİSİ) ═══
  1. Tüm istekleri bir Collection altına ekleyin
  2. Collection → Edit → Authorization → Bearer Token → {{access_token}}
  3. Artık TÜM isteklerde token otomatik eklenir!
     (Sadece Login/Register için "No Auth" seçin)


──────────────────────────────────────────────────────────────────────────────────────
 ADIM 4: REFRESH TOKEN KULLANIMI
──────────────────────────────────────────────────────────────────────────────────────

  Token süresi dolduğunda (5 dk):
  POST {{base_url}}/api/auth/refresh
  Body:
  {
      "refreshToken": "{{refresh_token}}"
  }

  Scripts'e ekleyin:
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  if (pm.response.code === 200) {                                            │
  │      var jsonData = pm.response.json();                                     │
  │      if (jsonData.access_token)                                             │
  │          pm.environment.set("access_token", jsonData.access_token);         │
  │      if (jsonData.refresh_token)                                            │
  │          pm.environment.set("refresh_token", jsonData.refresh_token);       │
  │      console.log("✅ Token yenilendi!");                                    │
  │  }                                                                          │
  └─────────────────────────────────────────────────────────────────────────────┘
