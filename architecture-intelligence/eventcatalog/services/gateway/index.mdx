**Current role:** Routes public API traffic to internal HTTP services and validates Keycloak JWTs. It also forwards identity headers and supports SSE token adaptation.\n\n**Important boundary:** Internal services currently trust forwarded identity headers; this is not yet a zero-trust service identity boundary.
