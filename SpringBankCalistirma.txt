
Docker Ile Build edip Docker imageye donusturme
docker build -t SpringBankWithMicroservices/auth-service:1.0.0 ./auth-service
docker build -t SpringBankWithMicroservices/user-service:1.0.0 ./user-service
docker build -t SpringBankWithMicroservices/money-service:1.0.0 ./money-service
docker build -t SpringBankWithMicroservices/transaction-service:1.0.0 ./transaction-service
docker build -t SpringBankWithMicroservices/gateway:1.0.0 ./gateway
docker build -t SpringBankWithMicroservices/fraud-service:1.0.0 ./fraud-service
Kubernet Icin Metrics server
kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml
Duz Kubernet Ayarlari
kubectl apply -f k8s/01-base.yaml
kubectl apply -f k8s/02-apps.yaml
Podlari getir.
kubectl get pods -n banking-microservices

Ekstra ->
Podlari ve Deploymentleri Sil
kubectl delete -f k8s/02-apps.yaml
kubectl delete -f k8s/01-base.yaml

Podlar Restart
kubectl rollout restart deployment -n banking-microservices

Docker Imageleri sil
docker rmi SpringBankWithMicroservices/auth-service:1.0.0
docker rmi SpringBankWithMicroservices/user-service:1.0.0
docker rmi SpringBankWithMicroservices/money-service:1.0.0
docker rmi SpringBankWithMicroservices/transaction-service:1.0.0
docker rmi SpringBankWithMicroservices/gateway:1.0.0
docker rmi SpringBankWithMicroservices/fraud-service:1.0.0

namespace ile tum docker imageleri sil
docker rmi $(docker images "SpringBankWithMicroservices/*" -q)
