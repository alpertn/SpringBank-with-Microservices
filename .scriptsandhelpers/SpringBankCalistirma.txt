Bu dosya guncel proje yapisina gore hazirlandi. Projede artik klasik
money-service yaninda CQRS icin ayrilmis money-service-command ve
money-service-query servisleri de var. Query tarafi MongoDB ve
Elasticsearch kullanir.
Gateway'deki admin backend mantigi da admin-service, admin-service-command ve
admin-service-query olarak ayrildi.

3) Image build
--------------

Menulu calistirma dosyasi:

  .\springbankcalistirma.bat

Menudeki ana secenekler:

  1. Her seyi yap
     - Image build
     - Kubernetes dosyalarini uygula/guncelle
     - Deployment restart
     - Pod durumunu goster

  2. Sadece build et

  3. Calistir / Kubernetes dosyalarini uygula-guncelle

  4. Deployment restart et

  5. Durum goster

  6. Loglari izle

  7. Test calistir (dev)

4) Kubernetes deploy
--------------------

Metrics Server HPA icin gereklidir. Ilk kurulumda bir kere calistir:

  kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml

Altyapi servisleri:

  kubectl apply -f k8s/01-Base.yaml

Uygulama servisleri:

  kubectl apply -f k8s/02-Apps.yaml

Durum kontrolu:

  kubectl -n banking-microservices get deploy,hpa,pods
  kubectl -n banking-microservices get svc

Gateway localhost'ta gorunmuyorsa port-forward ac:

  kubectl -n banking-microservices port-forward svc/gateway 8095:8095


5) Restart ve yeniden deploy
----------------------------

  kubectl rollout restart deployment -n banking-microservices

  kubectl rollout restart deployment/gateway -n banking-microservices

  kubectl rollout restart deployment/admin-service-command -n banking-microservices

11) Guncel mimari notlari
-------------------------

- user-service kullanici kaydi, login, Keycloak entegrasyonu ve kullanici admin
  islemlerini yapar.
- money-service eski akisin ana para servisidir ve mevcut gateway route'u
  /api/money-service/** buraya gider.
- admin-service gateway'deki admin backend mantigini devralir; log stream,
  test loglari, operasyon merkezi, query transport secimi ve history okuma
  endpointleri buradadir.
- admin-service-command admin history write-side servisidir. PENDING ve
  COMPLETED/FAILED history kayitlarini Postgres'e yazar ve projection event'i basar.
- admin-service-query admin history read-side servisidir. Kafka projection
  eventlerini MongoDB ve Elasticsearch'e yazar, history sorgularini buradan cevaplar.
- money-service-command CQRS write-side servisidir. Create account, deposit,
  withdraw, block money ve transfer command endpointleri buradadir.
- money-service-query CQRS read-side servisidir. Kafka projection eventlerini
  MongoDB'ye yazar ve Elasticsearch indexini gunceller.
- transaction-service transaction olusturma, gecmis, admin istatistikleri,
  cancel/reverse ve saga endpointlerini tasir.
- fraud-service fraud kontrol Kafka akisinda calisir.
- gateway statik UI dosyalarini ve /api/** route'larini disariya acar.
